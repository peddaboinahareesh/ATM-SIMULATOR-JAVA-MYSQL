# ATM Simulator

## Project Description

ATM Simulator is a Java-based application developed using JDBC and MySQL. It allows users to perform basic ATM operations.

## Technologies Used

- Java
- JDBC
- MySQL
- Eclipse IDE

## Features

- User Login
- Check Account Balance
- Deposit Money
- Withdraw Money
- Mini Statement
- Database Connectivity

## Database

MySQL is used to store account details and transaction records.
